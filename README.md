
# CampusGPT

An AI-powered chatbot project designed to help users access useful information related to Indian colleges and campus life.

## Overview

Finding relevant college information can involve searching multiple websites and documents. CampusGPT explores how conversational AI and retrieval-based techniques can make information easier to access.

## Core Technologies

- **Backend:** FastAPI
- **Embeddings:** Hugging Face
- **Vector Database:** Chroma
- **Language:** Python

## Project Goals

- Provide a conversational interface for college-related queries
- Retrieve relevant information from an indexed knowledge base
- Explore semantic search and AI-assisted question answering
- Build a foundation for a more useful college information assistant

## Architecture

1. Collect and prepare supported information sources.
2. Generate embeddings for indexed content.
3. Store searchable vectors in Chroma.
4. Receive user queries through the backend.
5. Retrieve relevant information and generate a response using the configured AI pipeline.

## Future Improvements

- Expand the knowledge base
- Improve retrieval relevance
- Add source references to answers
- Build a user-friendly frontend
- Evaluate answer quality
